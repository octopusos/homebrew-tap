# Octopus Core Homebrew Tap

Homebrew tap for [Octopus Core Pty Ltd](https://octopusos.dev) tools.

## Install

```bash
brew install octopusos/tap/octoryn
```

## Available formulae

- **octoryn** — Octoryn LLM official command-line interface

## Update

```bash
brew update
brew upgrade octoryn
```
